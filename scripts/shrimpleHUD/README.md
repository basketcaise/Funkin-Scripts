# shrimpleHUD
User interface utility for Psych Engine that allows for easy and unrestricted creation of multiple 'HUD styles'. also kinda simple ig idk

**Will most likely conflict with other mods/scripts that modify the UI.**

Works with Downscroll, Upscroll, Middlescroll, and Botplay!

Supported versions: v0.7.3 and v1.0

Currently available HUD styles:
- sVanilla: shrimpleHUD's take on the classic HUD seen in the base game!
- Shrimple: shrimpleHUD's own custom HUD style!
- sKade: A simple recreation of Kade Engine's UI (with a few tweaks), based on KE 1.5.4!
- Minimal: A more minimalistic style. Comes with colorcoded accuracy and miss indicators.

Press **Tab** to switch between available HUD styles. Your currently selected HUD style will save and persist across all songs, even through game restarts.
